# FixMyCity — Municipal Service Delivery Portal

FixMyCity is a municipal service delivery reporting platform that allows residents to report, track, and escalate municipal service delivery issues while helping municipal staff manage and resolve requests efficiently.

- Resident service request submission
- Request tracking
- Public dashboard
- Ward-based map view
- Escalation system
- Admin request management
- Analytics and reporting support
