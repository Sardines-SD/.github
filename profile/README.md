# FixMyCity — Municipal Service Delivery Portal

FixMyCity is a web-based municipal service delivery platform that enables residents to report, track and escalate service delivery issues while helping municipal staff manage and resolve requests efficiently.

## About the Project

FixMyCity was developed as part of a Software Design project focused on improving transparency, accountability and communication between residents and municipalities regarding service delivery challenges.

The platform allows residents to:
- Submit municipal service delivery requests
- Track the progress of requests
- Escalate unresolved issues
- View public community reports through an interactive dashboard

Municipal administrators can:
- Manage and update requests
- Monitor escalated issues
- Access reporting and analytics features

---

## Main Features

- Resident service request submission
- User authentication and login system
- Request tracking and status updates
- Public dashboard for community visibility
- Ward-based interactive map view
- Escalation system for unresolved requests
- Admin request management
- Analytics and reporting support

## Running the Project Locally

Clone the repository:

```bash
git clone https://github.com/Sardines-SD/Start.git
cd Start
```

Install dependencies:

```bash
npm install
```

Run the application:

```bash
npm start
```

Then open the local server link displayed in the terminal inside your browser.

---

## Deployment

The application is deployed using Microsoft Azure App Service and integrates Firebase Authentication and Firestore services for backend functionality.
